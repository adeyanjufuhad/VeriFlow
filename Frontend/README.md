# VeriFlow Frontend

The frontend is a JavaScript React application built with Vite and Tailwind CSS.
Its sample dashboard data is illustrative; no live bank or backend integration
is connected.

## Setup

From this directory, install dependencies and start Vite:

```powershell
npm install
npm run dev
```

Create a production build with `npm run build`. Copy `.env.example` to `.env`
to set the local API base URL. Never put credentials or secrets in `VITE_`
environment variables.

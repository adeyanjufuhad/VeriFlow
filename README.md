# VeriFlow

VeriFlow is an AI loan officer that lives in WhatsApp, turning market traders'
everyday sales into verified financial records and working-capital credit from
banks.

## Frontend setup

The frontend uses React, Vite, Tailwind CSS, and JavaScript (ES modules and JSX).

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env` if you want to configure the API base URL.
3. Start the development server with `npm run dev`.
4. Create a production build with `npm run build`.

The app defaults to `/command-center`. Routes and pages are placeholders for the
upcoming dashboard implementation.
